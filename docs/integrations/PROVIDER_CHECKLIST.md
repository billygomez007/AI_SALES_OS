# Provider evaluation checklist

For each WhatsApp, AI model, telephony, payment, email, hosting and analytics vendor record: product eligibility by country; price list and variable charges; official API support; access scopes; retention/training policy; processing/subprocessor geography; DPA and legal terms; uptime/incident history; signed webhook support; idempotency; retry limits; data export and termination options; support SLAs; sandbox availability; security posture; operational fallback.

Do not enter secrets into this checklist. Keep contractual versions and review dates in private vendor records. Require legal review for regulated payments, marketing, personal data and voice recording.
